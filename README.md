# Heuristic-Evaluation
A beginner-friendly UI/UX project exploring usability evaluation through Nielsen's heuristics and Norman's design principles.
🧩 Heuristic Evaluation – Usability Analysis

📌 Project Overview

This project focuses on evaluating the usability of digital interfaces using established UI/UX design principles.

It explores Nielsen's usability heuristics and Norman's design principles to identify common usability problems and suggest practical improvements.

🎯 Project Objectives

- Understand the importance of usability evaluation.
- Explore Nielsen's 10 usability heuristics.
- Understand Norman's design principles.
- Identify common interface usability problems.
- Compare good and bad UI practices.
- Suggest improvements to create user-friendly interfaces.

📚 Concepts Covered

1. Nielsen's Usability Heuristics

- Visibility of system status.
- Match between system and real world.
- User control and freedom.
- Consistency and standards.
- Error prevention.
- Recognition rather than recall.
- Flexibility and efficiency of use.
- Aesthetic and minimalist design.
- Help users recognise and recover from errors.
- Help and documentation.

2. Norman's Design Principles

- Affordances.
- Signifiers.
- Mapping.
- Feedback.
- Constraints.

🔍 Usability Evaluation

A sample shopping interface was evaluated to identify usability issues.

Interface Element| Problem| Suggested Improvement
Add to Cart| No confirmation message| Show success feedback
Login Form| Unclear error message| Display helpful instructions
Navigation| Inconsistent layout| Maintain consistent navigation
Checkout| Allows incomplete details| Prevent invalid submission
